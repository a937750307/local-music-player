MusicT.space 需要 文件系统访问 API 来访问您的本地音乐文件。

您当前的浏览器不支持此功能。

推荐的桌面浏览器：

  • Google Chrome （86 版或更高版本）
  • Microsoft Edge （86 版或更高版本）
  • Opera （72 版或更高版本）

注意：移动端浏览器、Safari 和 Firefox 目前不支持文件系统访问 API。
