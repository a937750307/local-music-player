# 本地音乐播放器
![MIT logo](https://img.shields.io/badge/License-MIT-yellow.svg)
![pwa logo](https://img.shields.io/badge/PWA-ready-blue.svg)

本项目是基于原作者[YingRongjun](https://github.com/YingRongjun)的 [musict.space](https://github.com/YingRongjun/musict.space) 开源项目二次开发而成的。

本地音乐播放器 是在线纯前端音乐管理器。与流媒体服务不同，它专注于帮助您管理和欣赏您已有的音乐。无需安装，无需上传 — 直接播放您存储中的音乐文件。

在线体验 [https://localmusic.937788.xyz](https://localmusic.937788.xyz)（推荐使用：桌面端 Chrome、Edge 或 Opera）

主要功能：
- 本地文件夹导入 – 通过文件系统访问 API 直接选择您的音乐文件夹。不会复制或上传您的文件。
- 智能元数据补全 – 自动从 MusicBrainz 获取缺失的标题、艺术家、专辑和年份信息。
- 自动专辑封面 – 从多个来源（Cover Art Archive、iTunes 等）获取封面图片并嵌入到您的音乐库中。
- 智能整理 – 自动按艺术家和专辑对您的音乐进行分组。再也不用面对杂乱的文件列表了。
- 我的歌单 – 一键收藏系统，构建您的个人音乐收藏集。
- 深色主题 – 精心设计的现代深色界面，长时间聆听更舒适。
- 支持 29 种语言 – 自动匹配浏览器的语言设置，照顾全球用户。

快速开始
- 操作系统：Windows、macOS 或 Linux
- 浏览器：最新的 Chrome、Edge 或 Opera，以支持完整的文件夹访问功能。

在线使用：
- 使用支持的浏览器打开 [https://localmusic.937788.xyz](https://localmusic.937788.xyz)。
- 点击侧边栏中的「导入音乐」按钮。
- 导入您的音乐文件夹或选择您的音乐文件。
- 等待扫描完成 — 您的音乐库将自动整理！

## 使用场景

- **音乐收藏爱好者** - 拥有大量本地音乐文件，希望有漂亮的封面和完整的元数据整理
- **隐私敏感用户** - 不希望将音乐上传到云端，只想在本设备上管理播放
- **轻度使用用户** - 不需要专业播放器的复杂功能，只需要简单好用的音乐管理
- **多语言用户** - 支持 29 种语言，适合不同语言背景的用户

## 其他

**资源占用说明：**（相比第三方客户端如网易云、QQ音乐等）

- **内存**：网页版依赖浏览器，基础内存较高但可控；本地播放器更轻量
- **CPU**：播放时 CPU 占用都很低，主要差异在界面渲染
- **磁盘**：本项目零安装，其他客户端需占用数百MB
- **启动**：本项目无需启动，打开浏览器即可；本地客户端需几秒启动时间

**网络使用：**

- 本项目仅在获取封面/元数据时消耗流量（按需），播放不产生流量
- 网易云/QQ音乐需要持续网络连接听在线歌曲（高流量）
- 离线模式下本项目完全不消耗流量
